# ตรวจสอบการเปลี่ยนเป็น AI Learning Studio

## สิ่งที่เปลี่ยน

- Sidebar เลือก AI ตามลำดับ Nui, Saimai, Bam, Bas, Kaka, SabaiTae
- ทั้งหกใช้ฐานความรู้และขอบเขตบทเรียนเดียวกัน เปลี่ยนเฉพาะรูปแบบการสอน
- ใช้ชื่อผู้เรียนเพื่อแสดงผล ไม่ใช้ชื่อเป็นตัวค้นประวัติ
- ประวัติแยกตามรหัสสุ่มของเบราว์เซอร์และ AI ที่เลือก
- ฐานข้อมูลเก็บ hash ของรหัส ไม่เก็บรหัสเบราว์เซอร์โดยตรง
- ตารางใหม่ไม่แทนที่หรือลบประวัติแบบเดิม
- ใช้โทนสีและโครงหน้าจาก Stitch โดยไม่เพิ่มปุ่มจำลองที่ใช้งานไม่ได้

## การจำประวัติ

รหัสเบราว์เซอร์เป็นกุญแจเข้าถึงประวัติ ไม่ใช่ระบบล็อกอิน
ชื่อเหมือนกันไม่รวมประวัติ และเปลี่ยนชื่อไม่เปลี่ยนเจ้าของประวัติ
ล้างข้อมูลเว็บไซต์ เปลี่ยนเบราว์เซอร์ หรือเปลี่ยนเครื่อง จะไม่เห็นประวัติเดิม
หากเบราว์เซอร์ปิดกั้น storage ระบบจะแจ้งว่าจำได้เฉพาะ session
ควรหลีกเลี่ยงใช้บนเครื่องสาธารณะ

ตาราง `browser_chat_owners` และ `browser_chat_exchanges` อยู่ใน
[chat_history.sql](../db/chat_history.sql) และเปิด Row Level Security
โดยไม่สร้าง public API policy ใช้ผ่าน PostgreSQL ฝั่ง server เท่านั้น
การบังคับ RLS ต้องตรวจด้วย PostgreSQL จริง ไม่ใช่ SQLite

## สถานะการตรวจ

ตรวจเมื่อ 29 กันยายน 2026:

- `venv/bin/python -m unittest discover -s tests`: ผ่าน 110 รายการ
- ชุดเฉพาะ persona/language/history/avatar/AppTest: ผ่าน 42 รายการ
- `node tests/test_browser_identity.mjs`: ผ่าน การจำรหัส รหัส canonical
  การอ่านกลับหลังเขียน storage กรณี storage ถูกปิด และ race จำลอง
- Chrome จริง: ตรวจ DOM และภาพ desktop กับมือถือ 390×844
  ตรวจการสลับ AI และปุ่มภาษา ช่องถามไม่ถูก sidebar บัง
  ปุ่มภาษาอยู่ขวาของช่องถามใน desktop และเหนือช่องถามในมือถือ
- PostgreSQL จริง: schema, เจ้าของ/AI แยกกัน, ชื่อซ้ำ, เปลี่ยนชื่อ,
  preview bytes, retry ไม่ซ้ำ, ลบเฉพาะ AI และ RLS ของ role authenticated ผ่าน
  ตรวจใน transaction ที่ rollback ทั้งหมด ไม่ทิ้งข้อมูล/schema ทดสอบ
- RAG + Gemini จริง: Nui ตอบ Bubble Sort ภาษาไทย และ Saimai ตอบ
  Counting Sort ภาษาอังกฤษ ได้หลักฐาน 5 chunks ต่อคำถาม
  ไม่มีการ re-index หรือบันทึกบทสนทนาจากสคริปต์ตรวจนี้
- `git diff --check`: ผ่าน

มีคำเตือนจาก parser PDF เรื่อง fontTools/offset ในเอกสารเดิม,
คำเตือน bare-mode ของ Streamlit AppTest และคำแนะนำ AFC ของ google-genai
ชุดเทสผ่าน แต่ไม่ได้หมายความว่าไม่มี warning หรือรับประกันไม่มีบั๊ก

ยังไม่ได้ตรวจ:

- รีเฟรช/เปิด Chrome ใหม่แล้วโหลดบทสนทนาจริงครบวงจรผ่าน UI
- เปิดหลายแท็บจริงพร้อมกันเพื่อทดสอบการแย่งเขียนรหัสเบราว์เซอร์
- ทุกบุคลิกกับทุกคำถาม/อุปกรณ์ ไม่ใช่เพียงกรณีที่ตรวจครั้งนี้

Preview ที่ port 8502 ปิด API key และฐานข้อมูลโดยเจตนา
ใช้ตรวจหน้าจอ ไม่ใช้พิสูจน์ว่าระบบประวัติหรือ AI จริงทำงาน
หลักฐาน PostgreSQL และ Gemini ข้างต้นมาจากสคริปต์ตรวจแยกต่างหาก
แอปจริงจะสร้างตารางประวัติใหม่เมื่อเชื่อมต่อสำเร็จครั้งแรก

## รูปทั้งหกคน

เพิ่มรูปใน `assets/avatars/` ตามรหัส `nui`, `saimai`, `bam`, `bas`,
`kaka`, `sabaitae` รองรับ `.png`, `.jpg`, `.jpeg`, `.webp`
ตัวอย่าง `assets/avatars/nui.png` ระบบจัดเป็นรูปวงกลมและใช้ทั้ง sidebar
หัวแชท และข้อความของ AI ถ้ายังไม่มีรูปหรืออ่านไม่ได้จะใช้ตัวอักษรแทน

## การทดสอบก่อนใช้งานจริง

1. ตั้งค่า secrets ฝั่ง server โดยไม่ใส่ลง Git
2. เปิดแอปจริงและตรวจว่าตารางประวัติสร้างสำเร็จ
3. ใช้ชื่อเดียวกันในสอง browser profiles แล้วถามคนละคำถาม
   ประวัติต้องไม่ปะปน
4. สลับ AI ทั้งหก ถาม แล้วรีเฟรช ประวัติต้องกลับมาที่ AI คนเดิม
5. เปลี่ยนชื่อ ประวัติต้องยังอยู่
6. ตัดการเชื่อมต่อฐานข้อมูล ระบบต้องแจ้งบันทึกไม่สำเร็จ
   และไม่ลบข้อความที่แสดงไปแล้ว
7. ทดสอบยกเลิกและยืนยันลบแชท ต้องกระทบเฉพาะ AI ที่เลือก
8. ทดสอบภาษาไทย/อังกฤษ การอ้างอิงและภาพต้องตรงกับคำถาม
9. ตรวจ desktop/mobile ว่าช่องถามและปุ่มภาษาไม่ทับกัน
